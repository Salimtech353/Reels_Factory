# রিল কারখানা — বাংলা স্ক্রিপ্ট থেকে ভিডিও

টাইমস্ট্যাম্প সহ বাংলা স্ক্রিপ্ট + ভয়েসওভার অডিও দিলে, স্বয়ংক্রিয়ভাবে প্রতিটা লাইনের জন্য প্রাসঙ্গিক কপিরাইট-ফ্রি ছবি/ভিডিও (Pexels/Pixabay) খুঁজে বের করে এবং **Shotstack**-এর ক্লাউড রেন্ডার ইঞ্জিন দিয়ে চূড়ান্ত ভিডিও বানিয়ে দেয়। ভিডিও প্রসেসিং সম্পূর্ণ **Shotstack-এর সার্ভারে** হয় — তাই মোবাইল ব্রাউজারের মেমোরি/পারফরম্যান্স সীমাবদ্ধতা নিয়ে ভাবতে হয় না।

## Netlify-এ ডিপ্লয় করবেন যেভাবে

1. [app.netlify.com](https://app.netlify.com) এ লগইন করুন
2. "Add new site" → "Deploy manually" এ যান
3. এই পুরো ফোল্ডারটা (zip না করে, ফোল্ডার হিসেবে) ব্রাউজারে ড্র্যাগ করে ছেড়ে দিন
4. কয়েক সেকেন্ডেই একটা লাইভ URL পাবেন

কোড আপডেট করার পর আবার ডিপ্লয় করতে চাইলে Netlify dashboard-এ সাইটে ঢুকে "Deploys" ট্যাব থেকে ফোল্ডারটা আবার drag-drop করলেই নতুন ভার্সন লাইভ হয়ে যাবে।

## ব্যবহারের আগে যা লাগবে (সবই ফ্রি)

| চাবি | কোথা থেকে | কী কাজে |
|---|---|---|
| Groq API Key — বিশ্লেষণ (প্রধান) | https://console.groq.com/keys | স্ক্রিপ্ট বিশ্লেষণ (ইংরেজি ফুটেজ-সার্চ কি-ওয়ার্ড বের করা) |
| OpenRouter API Key — ফলব্যাক | https://openrouter.ai/keys | Groq ব্যর্থ হলে বিশ্লেষণ, এবং Gemini ব্যর্থ হলে ট্রান্সক্রিপশন — একটা মডেল ব্যর্থ হলে পরের শক্তিশালী মডেলে যায়। শুধু এই চাবি দিলেও সব কাজ চলে |
| Gemini API Key — ট্রান্সক্রিপশন (প্রধান) | https://aistudio.google.com/apikey | অডিও থেকে সরাসরি বাংলা ট্রান্সক্রিপ্ট বানানো |
| Pexels API Key | https://www.pexels.com/api/ | ছবি/ভিডিও সার্চ |
| Pixabay API Key (ঐচ্ছিক ব্যাকআপ) | https://pixabay.com/api/docs/ | ছবি/ভিডিও সার্চ |
| Shotstack API Key (Sandbox) | https://dashboard.shotstack.io/register — রেজিস্ট্রেশনের পর ড্যাশবোর্ডে "Sandbox" key পাবেন | ভিডিও রেন্ডার |

**API ফলব্যাকের ক্রম:**
- স্ক্রিপ্ট বিশ্লেষণ: Groq → (ব্যর্থ হলে) OpenRouter মডেল-চেইন
- অডিও ট্রান্সক্রিপশন: Gemini → (ব্যর্থ হলে) OpenRouter অডিও-মডেল চেইন

OpenRouter-এর চেইনে একটা মডেল ব্যর্থ (লিমিট/ত্রুটি/অসম্পূর্ণ উত্তর) হলে পরের আরও শক্তিশালী মডেলে যায়। বিশ্লেষণের ডিফল্ট চেইন: `openai/gpt-oss-120b` → `google/gemini-2.5-flash` → `deepseek/deepseek-chat-v3.1` → `google/gemini-2.5-pro` → `anthropic/claude-sonnet-4.5` → `openrouter/auto`। ট্রান্সক্রিপশনের চেইন: `google/gemini-2.5-flash` → `google/gemini-3-flash-preview` → `google/gemini-2.5-pro` → `google/gemini-3-pro-preview` → `openai/gpt-4o-audio-preview`। OpenRouter-এ যে মডেল আর নেই সেটা নিজে থেকেই বাদ যায়। পরের দিকের মডেলগুলো পেইড হতে পারে — OpenRouter-এ ক্রেডিট রাখুন।

চাবিগুলো শুধু আপনার ব্রাউজারে (localStorage) সংরক্ষিত থাকে। Netlify Functions শুধু API কল forward করে — কোনো চাবি কোডে হার্ডকোড করা নেই।

## স্ক্রিপ্ট ফরম্যাট

```
00:00-00:05 | পাহাড়পুর বৌদ্ধ বিহার একটি প্রাচীন স্থাপত্য নিদর্শন
00:05-00:12 | এটি বাংলাদেশের নওগাঁ জেলায় অবস্থিত
00:12-00:18 | প্রতিদিন শত শত পর্যটক এখানে ভিড় করেন
```
প্রতি লাইনে: `শুরু-শেষ | বাংলা লাইন`। mm:ss অথবা hh:mm:ss দুটোই চলবে। টাইমস্ট্যাম্প আপনার আসল অডিওর সাথে মিলিয়ে দেওয়া জরুরি — নাহলে দৃশ্য পরিবর্তন কণ্ঠের সাথে সিঙ্ক থাকবে না।

## কীভাবে কাজ করে (আর্কিটেকচার)

```
১. বাংলা স্ক্রিপ্ট  →  Netlify Function (keywords.js)  →  Groq API (ব্যর্থ হলে OpenRouter)
                                                            (নির্ভুল ইংরেজি সার্চ কি-ওয়ার্ড)
২. কি-ওয়ার্ড  →  Netlify Function (search-media.js)  →  Pexels/Pixabay
                                                          (থাম্বনেইল প্রিভিউ, ম্যানুয়াল বাছাই/আপলোড)
৩. অডিও + বাছাইকৃত মিডিয়া  →  Netlify Function (shotstack.js)  →  Shotstack Ingest API
                                                                    (লোকাল ফাইল আপলোড হয়ে URL পায়)
৪. টাইমলাইন JSON  →  Netlify Function (shotstack.js)  →  Shotstack Edit API
                                                          (ক্লাউডে রেন্ডার, ফলাফল পোল করা হয়)
৫. চূড়ান্ত mp4 লিংক  →  ব্রাউজারে প্রিভিউ + ডাউনলোড
```

Pexels/Pixabay থেকে পাওয়া মিডিয়া সরাসরি তাদের URL হিসেবে Shotstack-কে পাঠানো হয় (Shotstack নিজেই ফেচ করে নেয়)। শুধু আপনার নিজের আপলোড করা অডিও/ছবি/ভিডিও ফাইল প্রথমে Shotstack-এর Ingest API দিয়ে আপলোড করে একটা ব্যবহারযোগ্য URL বানানো হয়।

## দৃশ্য টাইমিং ও মসৃণ ট্রানজিশন

প্রতিটা ভিডিও ক্লিপ ঠিক তার সেগমেন্টের টাইমস্ট্যাম্প জুড়েই চলে — সোর্স ভিডিওর দৈর্ঘ্য জানা থাকলে (Pexels/Pixabay মিডিয়া বা আপনার নিজের আপলোড করা ভিডিও, দুটোরই দৈর্ঘ্য স্বয়ংক্রিয়ভাবে বের করা হয়) স্বয়ংক্রিয়ভাবে প্লেব্যাক স্পিড সমন্বয় করা হয়:
- ভিডিও ক্লিপ সেগমেন্টের চেয়ে ছোট হলে → স্লো মোশনে চালিয়ে পুরো সেগমেন্ট ভরাট করা হয়
- ভিডিও ক্লিপ সেগমেন্টের চেয়ে বড় হলে → দ্রুত চালিয়ে ঠিক সেগমেন্টের মধ্যে শেষ করা হয়

প্রতিটা দৃশ্যের মাঝে জনপ্রিয় ও আধুনিক কয়েকটা ট্রানজিশন (fade, slideLeft/Right/Up, zoom, carouselLeft/Right, wipeLeft/Right) পালাক্রমে ঘুরিয়ে-ফিরিয়ে বসানো হয়, যাতে পুরো ভিডিওতে বারবার একই ইফেক্ট না দেখায় এবং দেখতে বেশি আকর্ষণীয় লাগে।

## ক্যাপশন (সাবটাইটেল)

"ভিডিও তৈরি" প্যানেলে একটা সুইচ আছে — চালু থাকলে স্ক্রিপ্টের প্রতিটা লাইন ঠিক তার টাইমস্ট্যাম্প অনুযায়ী **মূল ফুটেজের নিচের অংশে, কালো বর্ডারের ঠিক উপরে** ক্যাপশন হিসেবে দেখানো হয়। ক্যাপশন **একবারে মাত্র এক লাইন** দেখায় — টেক্সট বড় হলে সমান-সমান অংশে ভেঙে একটার পর একটা একই জায়গায় দেখানো হয়: প্রথম লাইন দেখানোর পর মুছে যায়, সাথে সাথে দ্বিতীয় লাইন শুরু হয় (প্রতিটা লাইনের সময় তার দৈর্ঘ্য অনুপাতে সেগমেন্টের সময় থেকে ভাগ হয়)। কাস্টমাইজ করতে পারবেন:
- **ফন্ট সাইজ**: ৮ থেকে ১৮ — সংখ্যা যত বড়, ফন্ট তত বড় (৮ সবচেয়ে ছোট, ১৮ সবচেয়ে বড়; ডিফল্ট ১৩ — HD ভিডিওতে যা মোটামুটি প্রচলিত সাবটাইটেলের আকার)। ফন্টের মাপ ফুটেজ-বক্সের ছোট বাহুর সাপেক্ষে হিসাব হয়, তাই ল্যান্ডস্কেপ/ভার্টিক্যাল/স্কয়ার — তিন ফরম্যাটেই একই সংখ্যায় প্রায় একই আকার আসে
- **রঙ**: সাদা / হলুদ / সবুজ / লাল / সায়ান / কালো
- **অ্যানিমেশন** (৭টা): টাইপরাইটার (ডিফল্ট) / ফেড ইন / নিচ থেকে উপরে স্লাইড / পাশ থেকে স্লাইড (বামে) / জুম ইন / ওয়াইপ (বামে) / কিছুই না (তাৎক্ষণিক)

ক্যাপশনে কোনো বর্ডার/আউটলাইন বা ব্যাকগ্রাউন্ড বক্স নেই — শুধু নির্বাচিত রঙের টেক্সট (খুব হালকা রঙের ফুটেজে পড়তে সমস্যা হলে ক্যাপশনের রঙ বদলে নিন)। ক্যাপশনের লেখা তার বক্সের *নিচ-সারিবদ্ধ*, আর বক্সের নিচের কিনারা ফুটেজের নিচের কিনারার ঠিক উপরে বসানো হয় — তাই ক্যাপশন না ভিডিওর মাঝখানে যায়, না বর্ডারে পড়ে। Shotstack-এর ডিফল্ট ফন্টে বাংলা লেখা ঠিকমতো দেখায় না (খালি বক্স আসে), তাই বাংলা-সাপোর্টেড **Hind Siliguri** ফন্ট আলাদাভাবে লোড করে ব্যবহার করা হয়েছে — এজন্য অতিরিক্ত কোনো সেটআপ লাগে না, স্বয়ংক্রিয়ভাবেই কাজ করবে।

## সাম্প্রতিক রেন্ডার

প্রতিটা সফল রেন্ডার বাম পাশে প্লেয়ারের নিচে "সাম্প্রতিক রেন্ডার" তালিকায় জমা থাকে (সর্বোচ্চ ১০টা, আপনার ব্রাউজারের localStorage-এ)। যেকোনোটাতে ক্লিক করলে সেটা আবার প্লেয়ারে লোড হয়ে যায়। **মনে রাখবেন — Shotstack sandbox-এর ভিডিও লিংক প্রায় ২৪ ঘণ্টা পর মেয়াদোত্তীর্ণ হয়ে যায়**, তাই পছন্দের ভিডিও দ্রুত ডাউনলোড করে নিজের ডিভাইসে রেখে দিন।

## স্বয়ংক্রিয় ট্রান্সক্রিপশন

অডিও ফাইল আপলোড করার পর **"ট্রান্সক্রিপ্ট করুন" বাটনে চাপলে** Gemini (ট্রান্সক্রিপশনের জন্য দেওয়া আলাদা চাবি দিয়ে) অডিওটা শুনে টাইমস্ট্যাম্প-সহ বাংলা ট্রান্সক্রিপ্ট বানিয়ে স্ক্রিপ্ট বক্সে বসিয়ে দেয় (অডিও নির্বাচন করলেই এটা এখন আর নিজে থেকে চলে না — যাতে চাইলে স্ক্রিপ্ট নিজে হাতে বা অন্য কোথাও থেকে বসাতে পারেন)। এরপর:
- **ট্রান্সক্রিপ্টটা একবার মিলিয়ে দেখুন** — বিশেষ করে ব্যাকগ্রাউন্ড নয়েজ থাকলে বা উচ্চারণ অস্পষ্ট হলে ভুল হতে পারে
- দরকার হলে বক্সেই সরাসরি এডিট করুন, বা "ট্রান্সক্রিপ্ট করুন" আবার চেপে নতুন করে চেষ্টা করুন
- **~১২MB-এর বড় অডিও ফাইলে** অটো-ট্রান্সক্রিপশন এড়িয়ে যাওয়া হয় (Gemini-এর inline অডিও লিমিটের কারণে) — তখন স্ক্রিপ্ট নিজে টাইপ করে দিতে হবে
- **সেগমেন্টের সর্বোচ্চ দৈর্ঘ্য ২০ সেকেন্ড** — Gemini-কে নির্দেশ দেওয়া আছে এই সীমা মানার জন্য, আর কোনোভাবে বড় সেগমেন্ট এলেও কোড নিজে থেকে সেটাকে ভেঙে একাধিক ছোট সেগমেন্টে ভাগ করে দেয়

## ছবি/ভিডিও সার্চ

- **Pexels ও Pixabay দুটো থেকেই একসাথে** ফলাফল আনা হয় (দুটোরই চাবি দেওয়া থাকলে) — একটাতে ভালো ফলাফল না পেলে অন্যটা থেকে পাওয়া যায়, ফলে বিকল্পের সংখ্যা বাড়ে
- Gemini প্রতিটা সেগমেন্টের জন্য একাধিক (subject + action + দৃশ্যপট মিলিয়ে) নির্দিষ্ট কোয়েরি তৈরি করে; প্রথম কোয়েরিতে ফলাফল না পেলে স্বয়ংক্রিয়ভাবে পরের কোয়েরি দিয়ে আবার চেষ্টা করা হয়
- মিডিয়া বাছাইয়ের পপ-আপে এখন **"← আগের" / "পরবর্তী →"** বাটন আছে — একই কোয়েরির আরও ফলাফল (পরের/আগের পাতা) দেখতে ব্যবহার করুন
- আপনি যে আউটপুট ফরম্যাট (ভার্টিক্যাল/ল্যান্ডস্কেপ/স্কয়ার) বেছে নিয়েছেন, সার্চ এখন **সেই orientation-এর ফুটেজকেই অগ্রাধিকার** দেয় (Pexels/Pixabay-কে সরাসরি সেই orientation-এর অনুরোধ পাঠানো হয়, আর ফলাফলও তা অনুযায়ী সাজানো থাকে) — তাই ভার্টিক্যাল ভিডিওতে ভুলবশত horizontal ফুটেজ চলে আসার সম্ভাবনা অনেক কমে যায়
- প্রতিটা থাম্বনেইলের উপরে একটা ছোট ব্যাজে **"ভার্টিক্যাল" / "ল্যান্ডস্কেপ" / "স্কয়ার"** লেখা থাকে, তাই কোনটা কোন শেপের তা সহজে বোঝা যায়। কোনো ফলাফল আপনার বাছাই করা ফরম্যাটের সাথে না মিললে ⚠ চিহ্ন দিয়ে সতর্ক করা হয়

## অন্যান্য সুবিধা

- **API চাবি প্যানেল এখন collapsible** — উপরের "API চাবি" শিরোনামে ক্লিক করলে সেকশনটা গুটিয়ে/খুলে যায়। চাবিগুলো আগে থেকে সংরক্ষিত থাকলে পেজ লোড হওয়ার সময় এমনিতেই গুটানো অবস্থায় থাকবে
- **প্রগ্রেস বারের পাশে সংখ্যায় শতাংশ** দেখা যায় (যেমন "৪৫%"), শুধু বার দেখে অনুমান করতে হয় না
- **API রেট-লিমিট সুরক্ষা**: "ট্রান্সক্রিপ্ট করুন" বা "স্ক্রিপ্ট বিশ্লেষণ করুন"-এ ক্লিক করে যদি "quota"/"rate limit" জাতীয় এরর আসে, তাহলে বাটনটা **৪০ সেকেন্ডের জন্য নিষ্ক্রিয়** হয়ে যায় এবং বাটনের উপর কাউন্টডাউন (৪০...৩৯...০) দেখায় — এই সময় আবার ক্লিক করা যাবে না, যাতে বারবার ব্যর্থ চেষ্টায় কোটা আরও দ্রুত শেষ না হয়

## ভিডিও ফরম্যাট (YouTube, Shorts, Reels, TikTok, Instagram)

"ভিডিও তৈরি" প্যানেলে **"ফরম্যাট (আকৃতি)"** ড্রপডাউন থেকে বেছে নিন:
- **ল্যান্ডস্কেপ ১৬:৯** (ডিফল্ট) — সাধারণ YouTube ভিডিও
- **ভার্টিক্যাল ৯:১৬** — YouTube Shorts, Instagram Reels, Facebook Reels, TikTok
- **স্কয়ার ১:১** — Facebook/Instagram ফিড পোস্ট

আলাদাভাবে **"মান (রেজোলিউশন)"** থেকে SD/HD (ডিফল্ট)/Full HD বেছে গুণমান ও রেন্ডার-গতির ভারসাম্য ঠিক করতে পারবেন। ক্যাপশন চালু থাকলে সেটাও বেছে নেওয়া আকৃতি অনুযায়ী সঠিক অনুপাতে বসে।

## ফুটেজের শেপ (ক্রপ, স্ট্রেচ নয়)

ফুটেজের অনুপাত আউটপুট ফরম্যাটের সাথে না মিললে (যেমন ভার্টিক্যাল ভিডিওতে horizontal ফুটেজ) সেটা `fit: "crop"` দিয়ে অনুপাত ঠিক রেখে স্কেল ও ক্রপ করা হয় — ছবি টেনে বিকৃত হয় না। (Shotstack-এর `cover` আসলে স্ট্রেচ করে, তাই সেটা ব্যবহার করা হয় না।) তবু ভিন্ন orientation-এর ফুটেজে অনেকটা অংশ কেটে যায়, তাই সার্চে আউটপুট ফরম্যাটের সাথে মেলা ফুটেজকেই অগ্রাধিকার দেওয়া হয়।

## কালো বর্ডার (Sandbox watermark ঢাকার কৌশল)

**"কালো বর্ডার"** ড্রপডাউন থেকে একটা মার্জিন সাইজ বেছে নিলে মূল দৃশ্য একটা নির্দিষ্ট (ছোট) পিক্সেল-বক্সের মধ্যে বসে, চারপাশে **ব্ল্যাক অ্যাশ রঙের** (নিরেট কালো নয়, সামান্য ধূসর-কালো) ফ্রেম থেকে যায় — ভার্টিক্যাল ও ল্যান্ডস্কেপ দুই ধরনের ফরম্যাটেই সমানভাবে কাজ করে, আর Ken Burns zoom effect দেওয়া থাকলেও সেটা এই বক্সের মধ্যেই আটকে থাকে (বর্ডারের উপর দিয়ে ছড়িয়ে পড়ে না)। ক্যাপশনও সবসময় এই ফুটেজ-বক্সের ভেতরেই (নিচের দিকে) বসে, বর্ডারের উপর কখনো দেখাবে না। Shotstack sandbox-এর watermark সাধারণত কোনো একটা কোণায় বসে, তাই এই মার্জিনের মধ্যে সেটা পড়ে যাওয়ার কথা। পরবর্তীতে ভিডিও এডিটরে (CapCut, Premiere, বা যেকোনো ভিডিও এডিটর) দিয়ে এই কালো বর্ডারটুকু ক্রপ করে ফেললে watermark-মুক্ত ফুল-ভিউ ভিডিও পাবেন।

**সতর্কতা:** watermark-এর সঠিক আকার/জায়গা Shotstack নিজে নির্ধারণ করে, তাই কোনো নির্দিষ্ট মার্জিন সাইজ ১০০% নিশ্চয়তা দেয় না। ব্যবহারকারীর পরীক্ষায় **১২-১৩%** পুরো watermark ঢাকতে যথেষ্ট হয়েছে, তাই এখন ডিফল্ট **১২%** — তবু রেন্ডারের পর একবার দেখে নিশ্চিত হয়ে নিন।

## স্থান-নির্দিষ্ট ছবি/ভিডিও নিয়ে গুরুত্বপূর্ণ কথা

Gemini-কে বিশেষভাবে নির্দেশ দেওয়া আছে যেন "পাহাড়পুর"-এর মতো নির্দিষ্ট নাম সাধারণ শব্দে (যেমন "mountain") রূপান্তরিত না হয়। তবে বাস্তবতা হলো: **Pexels/Pixabay গ্লোবাল স্টক সাইট** — বাংলাদেশের অনেক নির্দিষ্ট স্থানীয় স্থাপনার ছবি এদের লাইব্রেরিতে নাও থাকতে পারে। তাই:
- প্রতিটা সেগমেন্টে সার্চ কোয়েরি এডিট করে আবার সার্চ করা যায়
- নিজের সংগ্রহ থেকে ছবি/ভিডিও আপলোড করা যায় (মিডিয়া মডাল থেকে)

রেন্ডার শুরু করার আগে প্রতিটা থাম্বনেইল একবার দেখে নেওয়া ভালো অভ্যাস।

## জানা সীমাবদ্ধতা

- **Sandbox watermark**: ফ্রি Shotstack sandbox-এ আউটপুট ভিডিওতে ছোট watermark থাকে। এটা "development/testing"-এর জন্য — সত্যিকারের ইউটিউব চ্যানেলে নিয়মিত প্রকাশনার জন্য Shotstack-এর Terms of Service একবার দেখে নেওয়া ভালো; আসল প্রকাশনার জন্য চাইলে watermark-ছাড়া production tier প্রয়োজন হবে (পেইড)।
- **রেন্ডার সময়**: ক্লাউডে রেন্ডার হতে সাধারণত ৩০ সেকেন্ড থেকে ২-৩ মিনিট লাগে, ভিডিওর দৈর্ঘ্য ও রেজোলিউশনের উপর নির্ভর করে। এই সময় ট্যাব খোলা রাখুন — বন্ধ করলে পোলিং থেমে যাবে (রেন্ডার নিজে চলতে থাকবে কিন্তু ফলাফল দেখার জন্য নতুন করে আবার চালাতে হবে)।
- **ভিডিও ক্লিপের দৈর্ঘ্য**: Pexels-এর ভিডিও ক্লিপ সেগমেন্টের প্রয়োজনীয় দৈর্ঘ্যের চেয়ে ছোট হলে Shotstack তা লুপ না করে যতটুকু আছে ততটুকুই দেখাবে (শেষ ফ্রেম আটকে থাকতে পারে)। সমস্যা হলে সেগমেন্টের জন্য ছবি (photo) বেছে নেওয়া বা দীর্ঘতর ভিডিও ক্লিপ খুঁজে নেওয়া ভালো।
- **রেট লিমিট**: Pexels/Pixabay/Gemini/Shotstack প্রতিটারই ফ্রি টায়ারে সীমা আছে। অনেক সেগমেন্ট (২০+) একসাথে বিশ্লেষণ করলে মাঝে মাঝে থেমে যেতে পারে — কিছুক্ষণ পর আবার চেষ্টা করুন।

## বিশ্লেষণ ও Groq ফলব্যাক

- **বানান সংশোধন ফিচার সরানো হয়েছে** (`correct-transcript` ফাংশন নেই)। Gemini-র ট্রান্সক্রিপ্ট যেমন আসে তেমনই বসে; চাইলে নিজে বক্সে এডিট করুন।
- **কি-ওয়ার্ড সবসময় ইংরেজিতে** — UI বাংলা বা ইংরেজি যেটাই থাকুক। পুরো স্ক্রিপ্টের বিষয়/প্রসঙ্গ বুঝে প্রতি সেগমেন্টে ৪টি কোয়েরি (সবচেয়ে নির্দিষ্ট → নিরাপদ ফলব্যাক) তৈরি হয়; অ্যাপ সার্চে একে একে চেষ্টা করে।
- **বিশ্লেষণ (Groq → OpenRouter):** প্রথমে Groq (`openai/gpt-oss-120b`, তারপর `llama-3.3-70b-versatile`)। Groq ব্যর্থ হলে OpenRouter চাবি থাকলে চেইনের মডেলগুলো ক্রমান্বয়ে চেষ্টা হয়। মডেল বদলাতে Netlify-র Environment variables-এ `GROQ_MODEL`, `GROQ_FALLBACK_MODEL` ও `OPENROUTER_MODELS` (কমা দিয়ে আলাদা, দুর্বল → শক্তিশালী ক্রমে) সেট করা যায় (ঐচ্ছিক)।
- **ট্রান্সক্রিপশন (Gemini → OpenRouter):** Gemini ব্যর্থ বা লিমিট শেষ হলে OpenRouter-এর অডিও-সক্ষম মডেলে ব্রাউজার থেকেই সরাসরি চেষ্টা হয় (আলাদা ফাংশন লাগে না)।
